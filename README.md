# no-to-google-ai
Extensão para desabilitar as respostas de IA do Google Chrome.

Uma pesquisa normal que contenha a "Visão Gerada por IA" será recarregada excluindo isso.

Alterne entre as funções `removeAIByUrl()` `removeAIByDiv()` para remover esta seção
através da remoção da DIV ou da remoção via URL injection.
